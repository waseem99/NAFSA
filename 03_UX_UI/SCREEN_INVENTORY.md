# NAFSA Website Visual Screen Inventory

## Purpose
Define all visual screens required for the Codistan proposal prototype.

The goal is to demonstrate:

- understanding of NAFSA's mandate
- UX maturity
- regulatory platform thinking
- bilingual government experience

# Visual Rules

All screens should demonstrate:

- responsive behavior
- accessibility
- government-grade visual language
- consistent component usage
- bilingual readiness

---

# Prototype Success Criteria

The evaluator should understand within 5 minutes:

1. NAFSA is a regulatory knowledge platform.
2. Information discovery is the core experience.
3. The CMS supports controlled publishing.
4. Future integrations are possible.
5. Codistan understands government digital platforms.
