# Phase 3 — Core Regulatory Experience Screens

## Objective
Create the primary evaluator-facing experiences demonstrating NAFSA as a regulatory information platform.

## Screens

### 1. Market Access Intelligence
- Commodity search
- Destination market selection
- HS code discovery
- SPS requirements
- Regulatory documents
- Laboratory requirements

### 2. Regulatory Repository
- Search and filters
- Document taxonomy
- Notifications
- Standards
- Guidance documents

### 3. Laboratory Accreditation Directory
- Laboratory search
- Accreditation scope
- Product categories
- Status and validity information

## Design Principle
These screens demonstrate that NAFSA is not a conventional CMS website but a structured regulatory knowledge platform.
