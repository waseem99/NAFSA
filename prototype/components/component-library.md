# NAFSA Component Library

## Purpose

Reusable UI components for the Next.js prototype.

The design system should represent a government regulatory platform, not a marketing website.

---

# Global Components

## Header

Contains:

- NAFSA identity
- Primary navigation
- Language switcher
- Search access
- Employee portal access

Supports:

- English
- Urdu RTL

---

## Footer

Contains:

- Institutional links
- Contact information
- Regulatory resources
- PSW Trade Portal connection

---

# Content Components

## Regulatory Card

Used for:

- Regulations
- Notifications
- Guidelines
- Publications

Fields:

- Title
- Category
- Date
- Status
- Download action

---

## Alert Card

Used for:

- Pest alerts
- Disease notifications
- Regulatory warnings

States:

- Critical
- High
- Medium
- Information

---

## Laboratory Card

Fields:

- Laboratory name
- Accreditation status
- Scope
- Location
- Details action

---

## Search Component

Central experience across platform.

Capabilities:

- Keyword search
- Filters
- Categories
- Regulatory domains
- Documents

---

## Data Components

Used for:

- Statistics dashboard
- Regulatory insights
- Search results

Components:

- Tables
- Charts
- Filters
- Download controls

Mobile: 320px+

- Clear hierarchy
- High readability
- Minimal decoration
- Data-first presentation
- Accessible interactions
