# NAFSA Navigation System

## Purpose

Defines the navigation experience for a national SPS regulatory information platform.

The navigation prioritizes discovery of regulatory information rather than traditional corporate website browsing.

---

# Primary Navigation

Recommended structure:

- About NAFSA
- SPS Regulations
- Market Access
- Laboratories
- Pest & Disease Alerts
- Publications
- Statistics
- News & Updates

Utility actions:

- Search
- English / Urdu switch
- Employee Portal
- PSW Trade Portal

---

# Navigation Philosophy

Users should reach important regulatory information within two clicks.

Priority journeys:

1. Find export requirements
2. Find applicable regulations
3. Find accredited laboratories
4. Find alerts
5. Download official documents

---

# Header Structure

Desktop:

Logo

Primary navigation

Search access

Employee portal access

# Search-First Experience

Global search should always be accessible.

Search across:

- regulations
- documents
- alerts

# PSW Relationship

Navigation should include a clear transition:

NAFSA:
"Understand SPS requirements"

PSW:
"Proceed with trade transactions"

No embedded PSW transaction workflows are included in this prototype.
