# NAFSA Next.js Prototype

## Purpose

High-fidelity proposal prototype for NAFSA Digital Regulatory Platform.

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS

## Prototype Scope

The prototype will demonstrate:

- Public website experience
- Regulatory discovery
- Market access journey
- Laboratory search
- Alerts dashboard
- Employee portal concept
- CMS governance workflow
