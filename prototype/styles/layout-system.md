# NAFSA Prototype Layout System

## Purpose

Defines the spatial framework for the NAFSA Digital Regulatory Platform prototype.

The layout system supports a government-grade regulatory platform with:

- dense information presentation
- accessibility
- bilingual English/Urdu experiences
- responsive behaviour
- dashboards and structured content

---

# Grid System

## Desktop

Primary container:

- Maximum width: 1280px
- 12-column grid
- 24px column gap
- 32px page padding

## Tablet

- 8-column grid
- 24px page padding

## Mobile

- Single-column layout
- 16px page padding

---

# Page Templates

## Public Information Page

Structure:

1. Header
2. Breadcrumb
3. Page title
4. Intro summary
5. Main content
6. Related resources
7. Footer

---

## Search-Driven Pages

Used for:

- market access
- laboratories
- regulations
- publications

Structure:

Search/filter area

↓

Results list

↓

Detail view

---

## Dashboard Layout

Used for:

- statistics
- alerts
- monitoring

Structure:

Title

Key indicators

Charts/cards

Tables

Download actions

---

# Hero Sections

Hero sections should communicate authority, not marketing.

Recommended pattern:

- clear institutional headline
- supporting statement
- primary search/action
- relevant regulatory shortcuts

---

# RTL Layout Rules

Urdu experience must support:

- mirrored navigation
- right-aligned content
- RTL icons where applicable
- correct table behaviour
- bilingual switching without layout breakage

---

# Responsive Principles

Mobile priority areas:

- search
- alerts
- regulatory documents
- laboratory lookup

Complex tables should convert into:

- cards
- expandable rows
- filters

---

# Accessibility

All layouts must support:

- WCAG 2.1 AA
- keyboard navigation
- visible focus states
- readable contrast
- screen reader compatibility
