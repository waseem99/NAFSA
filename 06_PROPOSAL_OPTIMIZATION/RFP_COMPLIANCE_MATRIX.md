# NAFSA RFP Compliance Matrix

## Purpose

Maps major RFP requirements to the proposed Codistan solution, evidence location, and implementation approach.

| Requirement Area | Proposed Response | Evidence |
|---|---|---|
| Modern bilingual website | Next.js based responsive platform with English/Urdu RTL support | UX/UI prototype |
| Regulatory information platform | Structured SPS regulatory discovery experience | Market Access and Regulatory screens |
| CMS management | Strapi-based CMS with role-based governance | CMS workflow prototype |
| Maker-checker approval | Author → Reviewer → Approver → Publish lifecycle | CMS Workflow screen |
| Search capability | OpenSearch-ready regulatory discovery architecture | Search experience design |
| Employee portal | Secure internal information portal | Employee Portal prototype |
| Security controls | Keycloak, MFA, RBAC, audit logging approach | Security architecture |
| Future integrations | API-first architecture with integration readiness | Technical architecture |
| PSW relationship | Cross-navigation between NAFSA information services and PSW transaction platform | UX architecture |

## Evaluation Positioning

Codistan should position NAFSA as a digital regulatory platform, not only a website redesign.
