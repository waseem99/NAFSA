# NAFSA Technical Presentation Flow

## Objective

Demonstrate understanding of NAFSA as a national SPS regulatory information platform.

## Recommended Demo Sequence

### 1. Platform Vision

Explain:

- NAFSA regulatory information role
- Relationship with PSW
- Stakeholder value

### 2. Public User Journey

Demonstrate:

Homepage → Search → Market Access → Requirements → Documents

### 3. Regulatory Discovery

Show:

- Regulatory repository
- Search
- Filters
- Publications

### 4. Stakeholder Services

Show:

- Laboratory directory
- Alerts
- Statistics

### 5. Governance

Demonstrate:

Content author → Reviewer → Approver → Published

### 6. Technical Architecture

Explain:

- Next.js
- Strapi
- NestJS
- PostgreSQL
- OpenSearch
- Keycloak

### 7. Operations

Cover:

- Security
- Monitoring
- Support model
- Scalability
