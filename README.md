# NAFSA Digital Regulatory Platform

Codistan's solution repository for the NAFSA Website RFP.

## Purpose
This repository maintains the complete proposal, architecture, UX, prototype and delivery artefacts for the NAFSA digital platform.

## Approved Technical Baseline
- Next.js + React + TypeScript
- Strapi Headless CMS
- NestJS API Layer
- PostgreSQL
- OpenSearch
- Redis
- Keycloak IAM
- Object Storage
- Docker / Kubernetes-ready deployment
- Terraform / Helm
- CI/CD
- Prometheus / Grafana / Wazuh
- Matomo Analytics

## Repository Structure

- `01_RFP_Analysis` - RFP understanding and compliance
- `02_Solution_Architecture` - Technical architecture
- `03_UX_UI` - Brand, sitemap and visual system
- `04_Content_Model` - CMS and regulatory data modelling
- `05_Prototype` - Demonstration prototype
- `06_Security` - Security architecture and testing
- `07_Proposal` - Final proposal artefacts
- `08_Evidence` - Supporting evidence
