# NAFSA Technical Demo User Journeys

## Purpose

Define the recommended technical presentation flow.

---

# Journey 1 — Exporter / Stakeholder

Goal:
Find SPS compliance requirements.

Flow:

```
Homepage
  |
Search
  |
Market Access Intelligence
  |
Commodity + Destination Search
  |
Requirements Discovery
  |
Download Regulatory Documents
```

Demonstrates:

- search experience
- regulatory model
- stakeholder value

---

# Journey 2 — Regulatory User

Goal:
Publish a regulatory update.

Flow:

```
CMS Login
  |
Create Content
  |
Attach Documents
  |
Submit Review
  |
Approval
  |
Publish
```

Demonstrates:

- RBAC
- workflow governance
- auditability

---

# Journey 3 — Employee User

Goal:
Access internal information.

Flow:

```
Secure Login
  |
Employee Portal
  |
Office Orders
  |
Internal Notices
  |
Training Information
```

Demonstrates:

- secure portal
- role-based access

---

# Journey 4 — Search Discovery

Goal:
Find regulatory information quickly.

Flow:

```
  |

  |

  |

```

Demonstrates:
